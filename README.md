# 🎓 Smart Placement Hub

> A modern, responsive, and student-centric placement-preparation web application designed to help college students master Quantitative & Logical Aptitude, curated Java/DSA Coding Challenges, Mock HR & Technical Interviews, and structured Study Planning.

---

## 🌟 Key Features

- **📊 Structured Student Dashboard**: Real-time progress metrics, streak tracking, and daily tasks overview.
- **🧮 Aptitude Practice Arena**: Quantitative, Logical Reasoning, and Verbal Ability tests with difficulty filters (Easy, Medium, Hard), timers, and instant score analysis.
- **💻 Java & DSA Coding Platform**: Curated company-standard problems, topic filters (Arrays, Strings, Trees, DP), test cases, and clean mock editor.
- **🎙️ Mock Interview Simulator**: HR, Technical, Java, and DSA tracks with realistic prompt feedback and scorecards.
- **📅 Smart Study Planner**: Calendar-style task management with category tags, custom priorities, and streak tracking.
- **📈 Deep Analytics & Readiness Index**: Weekly performance charts, category accuracy breakdown, and weak area diagnostics.
- **🏆 Student Profile & Achievements**: Academic profile, skills inventory, and milestone achievement badges.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic markup, accessible elements, and SEO-optimized structure.
- **CSS3**: Vanilla modern CSS with CSS Custom Properties (Design Tokens), Flexbox/Grid, glassmorphism, and responsive breakpoints.
- **JavaScript (ES6+)**: Modular client-side architecture prepared for REST API integration.
- **Design System**: Plus Jakarta Sans & Inter typography, curated Indigo/Blue palette, micro-animations, and Font Awesome 6 icons.

## 🚀 Getting Started

### Prerequisites
You only need a modern web browser (Google Chrome, Firefox, Safari, Microsoft Edge).

### Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Nithi143/smart-placement-hub.git
   cd smart-placement-hub
   ```
2. Open `index.html` directly in any web browser or use a lightweight local server:
   ```bash
   # Using Python
   python -m http.server 3000

   # Or using Node.js
   npx serve .
   ```
3. Visit `http://localhost:3000` in your browser.
